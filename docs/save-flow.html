评价的数据形状

数据库、浏览器、评价文件都用同一个形状，所以可以互相读入。

{
  "r": { "lon": { "R-0033": 1 } },   // 地区 → 编号 → 评价
  "a": { "lon": { "R-0033": "eur" } }, // いいね（别的地区）→ 去哪
  "k": { "R-0237": "scene" },        // 手动改过的种类
  "t": 1791769493025                 // 保存时间
}

评价值：2 めっちゃいい（一定放进岛）・1 いいね・0 ふつう・-1 イマイチ

合并的规则

  1. 打开 Claude 页面：读数据库，再叠上这个浏览器里的评价。同一张图两边都有时，浏览器里的优先。然后整份写回数据库。
  2. 打开 Pages：从构建时的数据库快照开始，再叠上 github.io 浏览器里的评价，浏览器里的优先。
  3. 读入评价文件：文件里的优先，覆盖同一张图的评价。
  4. 重复・角度不同的图：评价转到保留的那张，整组只算一个评价。
  5. “共通”的图（不属于任何地区）：以前在各地区打的评价移到“共通”。

两个网页的评价不会自动同步。最好只在一个地方评价；在 Pages 评价时，记得保存成文件交给 Claude。
