# あつ森の島づくりの基礎（acnh-basics）

第47回のあと、ユーザーに「对动森构建岛屿的基础还不够 从基础开始巩固」「5分 一点都不惊艳」と言われて、6つに分けて調べ直した。
**C** = 確か（Nookipedia・データの解析・2つ以上の出どころが一致）、**U** = 不確か（ゲームで確かめる）。出どころの URL は ref/ の各メモ。

## 1. 島と地形

- 島は 7×6 エリア（1エリア 16×16）＝ **112×96 マス**。外まわりの1エリアは海岸（浜・岩・河口・桟橋・飛行場）。自由に工事できるのは内側の 5×4 エリア ＝ 80×64 マス（**C**）。外まわりのエリアの陸のふちをどこまで工事できるかは **U**（今の島には外まわりにも崖と川がある）。
- 動かせない：飛行場（南の浜・10×6）・案内所（6×4）と広場（12×10、物を置けない）・河口2つ（南、または南と東か西。北にはない）・桟橋・北の秘密の浜・浜の大岩。浜・河口・浜の岩は工事できない（**C**）。
- **崖**：上れるのは3段（4段目は作れるが上れず物も置けない）。崖は **2マス幅から**。段を重ねるときは下の段のふちから1マス内側（2段にするには下の段が4マス幅以上）。木・岩・建物・橋・坂・家具の近くには崖を作れない（木から1マス）。浜・岩の上は不可。崖の角はボタンで45°に丸められ、丸めた半マスには物も花も置けない（**C**）。崖の面の見た目は変えられない。
- **川・池**：水は木・岩・建物・橋・坂の近くには掘れない。浜には掘れない。魚が出るのは 3×3 以上の水。滝は上の段から崖のふちを掘って作り、両わきに崖が要る。崖は 2×3 以上、崖の角から1マスはなす。丸めた崖には作れない。3段の滝は2回（3→2→1）（**C**）。滝の幅は3マスまでが軽い（**U**）。
- **道**：土・草は無料、石・レンガ・黒土・アーチタイル・砂・テラコッタ・板は2000マイル、マイデザインの道は2300マイル。草の上にしか敷けない（マイデザインの道はどこでも）。**かたい道（石・レンガ・タイル・テラコッタ・板・マイデザイン）は、掘る・花を植える・花が増える・化石・岩の出現を止める**。家具は道の上に置ける（**C**）。
- **坂**：2×4（上の段に 2×1、下に 2×3）。縦横だけ（ななめ不可）。まわり1マスあける（坂を並べられない）。出入口は水に向けられない。案内所で注文、動かせない（**C**）。8種類。
- **橋**：幅4。水の幅3〜5をまたぐ。両岸に 4×1 の空き。ななめも可（岸が平行なら）。橋どうし1マス以上はなす。崖や別の川の近くは不可。8種類（**C**）。
- **数**：坂8・橋8（ver 2.0 の建設ライセンス Pro［3000マイル］でそれぞれ10）。**住民は坂と橋でしか動かない**（はしご・棒で行く所には来ない）（**C**）。

## 2. 建物

| 建物 | 大きさ（幅×奥） | 入口の前（掘れない・家具不可・道は可） |
|---|---|---|
| 自宅 | 5×4（増築しても同じ） | 3×2 |
| 住民の家（10軒まで） | 4×4 | 3×2 |
| 案内所 | 6×4（広場 12×10 は動かせない） | — |
| 博物館 | 7×4 | 3×1 |
| タヌキ商店 | 7×4（増築しても同じ） | 3×2（**U**）|
| エイブル | 5×4 | 3×2 |
| キャンプ場 | 4×4（4×3 という説も **U**）| 2×1 |
| 飛行場 | 10×6（**U**）| — |

- 土地の上の花・木・低木は消える。建物どうし、建物と坂・橋は1マスあける。**木は建物から1マス**。道と家具は建物にくっつけてよい。2段目・3段目の平地に建ててよい。入口はいつも南（**C**）。崖・川からの距離は **U**。
- 動かす：自宅 30000ベル、ほか 50000ベル、1日1つ。住民の土地は 10000ベル（**C**）。
- 住民の家の外観は住民ごと。ハッピーホームパラダイスで変えられる。自宅は案内所で屋根・壁・ドア・ポスト（2.0 で形も）。
- 広場：K.K.（土曜の夜）・行事・ことの・レックス・カブリバ。ジャスティン・ローラン・つねきちは島を歩く。つねきちの舟は北の秘密の浜。ジョニーは浜。ラコスケは桟橋（**C**／一部 **U**）。

## 3. 家具

- **外に置ける**：家具（床に置く物）・小物（台の上にも）・柵・像・化石・模型・魚と虫。**置けない：壁かけ（自宅のドアのかざりだけ）・ラグ・天井の物・絵・かさ（手に持つ物）**（**C**）。
- 置き方：ポケットから目の前のマスに置き、押す・引くで動かす。4方向に回る。外には模様がえモードはない。押し引きで半マスずれる（**U**）。2×2 の台のまん中に小物を置くには崖とはしごのワザが要る（**C**）。2.0 から、ぎっしり並べた家具のすきまを通れる。
- 置けない所：案内所の広場（**C**）・水・橋・坂・建物の入口の前・2段にまたがる所（**U**だが守る）。浜には置ける（**C**）。花と木の上には置けない（**U**）。
- **柵**：自分の向きに直角に置く。となりの柵とつながる（ななめはつながらない）。10本ずつ作る。30種類（2.0 で9種類増えた）。色を変えられる柵10種類（Custom Fencing in a Flash）（**C**）。
- **マイデザイン**：地面（道）と、模様を変えられる家具 226種（シンプルなパネル・屋台・木箱・鳥居・軽自動車・ヨット・物置・アウトドアベンチとテーブル・物干し・のぼり・看板・ポスタースタンド・storefront・城の壁と塔・バリケード など）。DIY の作業台か Cyrus で貼る。PRO デザイン：かさ・うちわ・旗・顔出し看板（PRO エディタ＋）。**崖の面・水には貼れない**（**U** だが前提にする）。
- **建物に見せるワザ**（**C**）：シンプルなパネル（1×0.5・高さ約1.3）にレンガ・窓・ドアのデザインを貼って並べる。**崖のすそにパネルを並べると崖が「壁」に見える**（R-1233・X-0003・R-1217 の作例）。崖の上に柵（レンガの柵など）を並べて胸壁にする。屋台2つ＋パネル1つで温室。冷蔵庫や自販機で崖の土を隠す。
- 同じ家具を 8×8 マスに6個より多く置くと評価が下がる（柵は別）。

## 4. 木・低木・花・作物

- **木**（**C**、データの解析）：苗が育つには**まわり8マス（ななめも）に木がない**こと、そして**崖・水・浜・建物・坂・橋のとなりでない**こと。家具・柵・花・低木はじゃまにならない。**大きくなった木は掘って植えかえれば、木どうしくっつけてよい**（ただし崖・水・浜・建物・坂・橋のとなりには植えられない）。4日で大人。
- 種類：広葉樹（4/1〜10 に桜。秋は黄・橙、11/16〜25 に紅葉）・針葉樹（どこでも）・果物の木（リンゴ・サクランボ・オレンジ・モモ・ナシ）・ヤシ（**浜か砂の道だけ**）・竹（まわり1マス）・金のなる木。
- **木は190本くらいまで**（木の点が220をこえると「木が多すぎる」で5つ星にならない）（**C**、数は **U**）。林は木を減らして**低木で埋める**。
- **低木**：場所の決まりなし（浜だけ不可）。となり合ってよい・建物にくっつけてよい → 生け垣になる。季節の花：ツバキ1〜3月・ツツジ4/11〜5月・アジサイ6/1〜7/20・プルメリア6/1〜9/20・ハイビスカス7/21〜9/20・キンモクセイ9/21〜10/31・ヒイラギ11〜12月（**C**）。
- **花**：8種類（バラ・チューリップ・パンジー・コスモス・ユリ・ヒヤシンス・アネモネ・キク）＋スズラン（5つ星のごほうび）。草地とやわらかい道（土・黒土・砂）に植えられる。交配には水やり、走ると傷む → 花壇には道を添える（**C**）。
- **作物**（2.0）：カボチャ・ニンジン・ジャガイモ・トマト・サトウキビ・小麦。場所の決まりなし（浜だけ不可）（**C**）。
- **岩**：6つ（1つは金の岩）。1日1つ戻る。水・崖・浜・家具・花・柵・道・デザイン・建物・木の近くには出ない → 空き地を1か所だけ残すと「岩の庭」になる（**C**／やり方は **U**）。

## 5. 遊びのための場所（毎日の遊び）

- 飛行場 → 案内所 → 店（タヌキ商店・エイブル・博物館）を1本の道で。入口と広場は人が通れる広さ。
- 2段目より上の川（イワナ・ヤマメ・ゴールデントラウト・オショロコマ）・河口（サケ・キングサーモン・チョウザメ）・池・桟橋・海。ヤシ（カブトムシ8種）・切り株（4種）・白い花・黒や青や紫の花（**C**）。
- 果樹園・竹・岩の庭・花の交配の畑・浜の空き。地面に落とした物は15個まで。

## 6. 島の評価（5つ星）

- 5つ星：開発 665以上・自然 450以上（**C**）。
- 開発：博物館・エイブル・増築したタヌキ商店・**坂と橋1本ずつ** 各+15。住民10人 +30。雑草100以下 +30。**柵1本 +0.2**。買った家具は1個約+1（高い家具・outdoor・3マス幅以上は加点）（**C**）。
- 自然：木 +1（190まで）・花 +0.5〜1・低木 +0.5・作物 +0.5〜1。DIY の家具はこちらに入る（**C**）。
- 家具は **8×8 マスのかたまりごと**に数え、種類が多いほどよい。**かたまりの64マスのうち45マス以上がふさがると「ごちゃごちゃ」で5つ星にならない**（建物・橋・岩・崖・川・坂は数えない）（**C**）。
- 道は点にならない。

## 7. 惊艳に見せる（ref/stunning.md）

- **地面**：草のままの所は「未完成」に見える。町は地面をマイデザインで敷きつめ（石畳・レンガ・板・落ち葉の土・苔）、道の**ふち**（草がかぶるふち・レンガのふち）と**よごれ**（割れた石・落ち葉）を重ねる。半透明の土の道で既製の道の固いふちを消す。ただし地区のあいだには草を残す（全部タイルだと「床のショールーム」）。
- **密度**：見せ場は 1マスに 0.6〜1個（6×8 マスに 20〜40個）。ただし 8×8 で45マス未満。にぎやかな所と静かな所を交互に。
- **高さ**：主役は2〜3段目、坂で上がる。崖はパネルで壁にして、上のふちに柵・花・低木。丸い角と四角い角をまぜる。川はななめと幅の変化、1マスの中島、2〜3段の滝。
- **構図**（カメラは北を向いたまま）：背の高い物は北（奥）、低い物は南（手前）。奥へだんだん高く。背の高い物を並べない。狭い通路の先でぱっと開ける。夜の明かり。
- **くり返さない**：同じ家具を並べず、左右をくずす。大きな花の市松はタイルに見える。
- **つまらない理由**：広すぎる道（本道4・小道2〜3）・まっすぐな線と整列・平らな地面と生の草と既製の道のふち・同じ物のくり返し・高い物の詰めこみ・どの地区も同じ密度。

## 8. 作業の順番（ゲームと同じ順）

1. 動かせない物（飛行場・案内所・河口・浜の岩・桟橋）を書く。
2. 建物の土地（住民10・店・博物館・キャンプ場・自宅）と、飛行場からの本道。
3. 崖・川（2マス幅・1マスの段・滝の決まり）・坂と橋（数と場所）。
4. 道（本道4・小道2〜3）と地面のデザイン。
5. 見せ場の家具（目録の名前・8×8 の決まり）、パネルで崖を壁に。
6. 木（190本まで・崖や水のとなりは不可）・低木の生け垣・花。
7. `python3 tools/acnh_build.py`・`python3 tools/island_check.py`・`node tools/test_plan2.js`。
