# 美的センスの判定（island-aesthetics）

組み立て台とマップに入れるのは、この基準で**採用**したモジュールだけ。1000個はデータベース（`db/modules.sqlite`）に保管し、
判定は理由つきで `db/curation-*.json` に1件ずつ残す（あとで見直せるように）。

## 1. 判定の基準（110点満点）

| 観点 | 点 | 見ること |
|---|---|---|
| テーマの一貫性 | 25 | その地区の素材と小物でできているか（例：日本＝砂利・灯籠・竹・鳥居）。ほかの地区の色が混ざると減点 |
| 役のはっきりさ | 15 | 主役（遠くから分かる顔）／脇役（人が集まる所）／すき間うめ／道ばた のどれかに迷わず入るか |
| 密度と余白 | 20 | 家具の割合0.3〜0.7が目安。主役は少し余白があるとよい |
| 重ねすぎない | 15 | 同じ型の色違いは1つ（多くて2つ。すき間うめは3つ） |
| 地形への収まり | 15 | 7×7より大きいのは主役だけ。水が要るものは川や海のある地区だけ |
| ゲームで作れるか | 10 | 実際の家具とマイデザインで再現できるか |
| 段差の加点 | +10 | 段を使って高低を見せるもの（坂を2本使うものは坂に余りがあるときだけ） |

- **70点以上＝採用**、50〜69点＝保留（控え）、50点未満＝不採用。
- 1地区の目安：主役2〜4・脇役8〜12・すき間うめ6〜10・道ばた2〜4・段差2〜4。
- 役：`landmark`（主役）／`support`（脇役）／`filler`（すき間うめ）／`edge`（道ばた）／`step`（段差）。

## 2. くり返しで分かった決まり（判定と配置に反映済み）

- 縁に飾りのある色違いだけを採ると、街灯や灯籠が林のように並ぶ → 「飾りなし」の色違いも採る。
- 色違いを入れ替えても多様にならない（作例は1地区に型が約20しかない）→ ちがう家具を組み合わせた飾りセット（`vig_*`）で多様さを出す。
- 岩のすき間うめが続くとがれきに見える → 砂漠や庭は地面の模様（砂地・砂利・石畳・ウッドデッキ）で埋める。
- 小物のすき間うめは回数の上限がなく細いすき間を占領する → 同じ大きさなら地面を先に選ぶ。

## 3. マップの決まり

- 島は 112×96 マス。x は東、y は南へ増える（左上が 0,0）。区画は行 A〜F（y÷16）・列 1〜7（x÷16＋1）。
- 地区は7つ：ロンドン・エジプト・日本・アメリカ・ハロウィン・ヨーロッパ・地中海の港。境目は `tools/gen_samples.py` の ZONES。
- 島の見た目が単調にならないこと（同じ小物が並ばない・色違いばかりにならない）。
- 段差を使うモジュールを優先して取り入れる。主役の下だけを台座のように上げず、先に島全体の高低を決める（地勢計画）。

## 4. あつ森の仕様（計画が守ること）

2026-10-07 に調べた仕様。ゲームでできない計画は意味がないので、ツールはこれを点検する。

| 項目 | 決まり |
|---|---|
| 案内所の広場 | 建物6×4と広場で12×10。家具もマイデザインも道も置けない。動かせない（地形 P） |
| 飛行場 | 動かせない。島のいちばん下 |
| 建物の大きさ | 博物館7×4・たぬき商店7×4・マイホーム5×4・仕立て屋5×4・住民の家4×4・キャンプ4×4（入口の前1マスを含む） |
| 建物の向き | 回せない。入口はいつも南。入口の前に家具は置けない（道は可） |
| 間隔 | 建物・橋・坂どうしは1マス以上あける。建物は平らな所に |
| 崖 | 使えるのは1〜3段。1マス内側から上げる。砂浜・岩場のとなりには作れない |
| 坂 | 2×4（崖の上に1マス、下に3マス）。まっすぐな崖だけ。水に向けない。隣の坂と1マスあける |
| 橋 | 川幅3〜5マス。橋の幅4（両岸を含めて6×4） |
| 数 | 橋と坂はそれぞれ8個まで（計画は8個以内） |
| 島の評価 | 8×8マスに同じアイテム7個以上で減点。45個より多いと星4止まり |
| 木 | まわり8マスが空いていること。ヤシは砂の上だけ |

## 5. 水と島の暮らし（第14回・ユーザーの指示 2026-10-11）

- **水は自然に任せず設計する。** 今の島の川・池は「勝手にあふれた川」に見えるので、いったん全部埋めて引き直す。
  川・水路はまっすぐと45度だけ・幅3にそろえる（`plan-design.json` の river。自然な川 stream は使わない）。あつ森で動かせない河口3つにはつなぐ。
- **滝は1〜2か所だけ。** 高台（2段目）の釣り場の池と、1段目の川をつなぐ所にだけ置く（エジプトの台地の池→ナイル川、北東の山の湖→運河）。
- **釣り場は1段目と2段目の両方。** 1段目は川・運河（テムズ川・ヨーロッパの運河）、2段目は高台の池・湖。海釣りは桟橋。
- **日本は枯山水。** 水を使わず、石と白砂で山水を表す。白砂には砂紋（箒目）を引く（記号 `m`）。川は「枯れ流れ」として白砂で表し、
  石組み（三尊石・亀島・龍安寺の見立ての石庭）と苔、竹垣、灯籠を合わせる。白砂を眺めること自体が心を整える場所になるように、物を詰めすぎない。
  日本の地区では水の要るモジュール（池・飛び石の池など）は採用しない。
- **住民の家はまだ決めない。** あとで少しずつ割り当てる（見本にも置かない）。
- **自宅は場所に理由をつけて決める。** どの地区へも歩いて近く、川をまたがずに案内所と商店へ行ける1段目の平らな所。自宅のそばに畑と果樹園を置く。
- **島の暮らしに要る所を入れる。** 採石場（岩6つを柵で囲んでたたける所）・畑（野菜）・果樹園（木は1マスあける）・釣り場・花の交配畑（市松に植える）・
  木材の林（アメリカの森林）・竹林（日本）。木・岩・花のまわりの空けるマスは記号 `l`。

## 6. 学んだこと（高低差の見せ方）

- あつ森のカメラは北を向くので、南の背の高い物は北の物を隠す。主役の後ろ（北）は陰になるので、細かい物を置かず背景（林の尾根など）にする。
- 主役の正面から近づく道までは「眺めの通り道」。背の高い物（塔・城壁・アーチ・電話ボックス・鳥居・柱・像・建物・木）を置かない。
- 主役の場所は島全体から探す（博物館はエジプト考古学博物館として砂漠の台地の南東のふもと（27,25）・B2 へ）。

## 7. 使い方

```
python tools/module_db.py import                  # modules-popular.json と追加セットを取り込む
python tools/module_db.py apply db/curation-*.json   # 判定を順に書き込む（あとの判定が前を上書き）
python tools/module_db.py stats                   # 役別・テーマ別の採用数
python tools/module_db.py export                  # modules-curated.json / .md を書き出す
```
