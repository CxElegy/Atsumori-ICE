# アイス島の図の描き方

ユーザーに指摘された失敗（ラベルが線に重なる、回転した文字、枠のすぐ横に押しこんだ矢印）を繰り返さないための決まり。
見本：`docs/save-flow.html`（保存の仕組みの図）。

## 配置
- 列（x）を先に決めて、列と列のすき間は **ラベルつきの矢印なら 90px 以上**、ラベルなしでも 60px 以上あける。
  足りなければ枠を詰めずに viewBox を広げる（横スクロールの `overflow-x:auto` の入れ物に入れ、`min-width` を viewBox に合わせる）。
- 行（y）も同じ。上下の枠のあいだを縦の矢印が通るときは 60px 以上。
- 戻りの線（下の枠から上の枠へ、右端の縦線など）は、ほかの枠から 20px 以上離れた専用の通り道を走らせ、viewBox の端から 10px 以上内側に置く。

## 矢印
- 向きが2つある流れ（保存と読みこみ）は、**別々の2本の平行線**にし、線と線のあいだを 30px 以上あける。1本の両矢印はやりとりが対等なとき（ブラウザ保存↔ページ）だけ。
- 矢印の端は枠の線から 4px 離す（矢じりが枠にめりこまない）。
- 線は直角に折る（`H`／`V` だけの path）。斜めの線は使わない。
- 線どうしの交差はできるだけ避け、どうしても交わるときは点線（参照だけの流れ）と実線にする。

## ラベル
- **文字は回転させない。** 縦の線のラベルも横書きにして線の横に置く（`text-anchor="end"` で線の左に寄せる）。
- ラベルは **2つの枠のあいだの空白の真ん中**に置き、`text-anchor="middle"`。線の上 8〜10px。
- すべてのラベルに背景色のふち取りをつけ、線が文字を切らないようにする：
  `paint-order: stroke; stroke: var(--paper); stroke-width: 5px; stroke-linejoin: round;`
- 短く：2〜6文字（「保存为文件 →」「← 读入」のように向きを文字でも示してよい）。
- 1本の線にラベルは1つ。同じ文字のラベルを2か所に置かない。

## 色と意味
- 色は流れの種類で決め、凡例に同じ線を描く：黒＝データ・網页の流れ、橙の点線＝浏览时只读（复制しない）、青＝ブラウザ保存、紫＝Claude ページの数据库、緑＝評価ファイル・Claude に渡す。
- 枠の線の色も同じ意味で使う（一時的なものは点線の枠）。
- 色はすべて CSS の変数（`:root` とダークの2つのブロック）。SVG の中に直接の色を書かない。

## 確かめ
- 書いたら1回スクリーンショット（playwright, 幅 1120）を撮り、次を見る：
  ラベルが線・枠・ほかの文字に重なっていないか、矢じりが枠に刺さっていないか、同じラベルが2つないか、古い要素の残り（置きかえたあとの切れ端）がないか。
- SVG を Python で部分的に置きかえたあとは、`<defs>`〜`</defs>` が壊れていないか（図がまるごと消える）を必ず確かめる。
