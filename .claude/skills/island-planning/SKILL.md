# 全島の計画（island-planning）

`island-aesthetics` はモジュール1つの良し悪し、この skill は**島ぜんたいの組み立て**。
順番はいつも **道の骨組み → 地区のさかい → 区画（囲まれた部屋）→ 目じるし → 家具**（CityEngine・SimWorld の都市の作り方と同じ：道が先、建物は道に沿って、小物は最後）。
家具を先に置いて、あとから道でつなぐと「草地にモジュールが落ちている」島になる（第44回の 4点の原因）。

## 0. 出どころ（何から学んだか）

| 出どころ | 取り入れたこと |
|---|---|
| ユーザーの「めっちゃいい」30件（ロンドン） | 地面はほぼ全部舗装・どの場面も壁で囲まれた部屋・北に背景の壁・さかいに柵や花箱・崖をレンガの壁にして段を重ねる |
| New Urbanism の **transect**（田園から都心への6段の断面） | 地区を都心 → 町 → 郊外 → 田園 → 自然 の順に並べ、となりは1段ずつしか変えない（なめらかな移り変わり） |
| Ebenezer Howard の田園都市・ロンドンの **Green Belt** | ロンドン市内を郊外と緑地帯（森）が輪のように囲む。案2の形そのもの |
| Kevin Lynch『都市のイメージ』 | 道（path）・へり（edge）・地区（district）・結び目（node）・目じるし（landmark）の5つで島を説明できること |
| 関卡設計（level-design skill：weenie・breadcrumb・vista・blur test） | 遠くから見える大きな目じるし、道の先に見える次の目標、登ったあとの眺め、ぼかしても行き先が分かる構図 |
| environment-art skill | 主役5%・脇役15%・骨組み50%・小物30%。何もない所も設計のうち（ただし縁で囲んだ空き） |
| Jane Jacobs・Jan Gehl・『パタン・ランゲージ』 | 道に面した店の並び（street wall）・やわらかいへり（座れる・見られる縁）・囲まれた外の部屋・道の先のゴール・入口の門 |

## 1. 骨組み：道は1本の背骨と輪

- **背骨（主軸）**：飛行場 → 案内所の広場 → ロンドンの中心 → 郊外 → 各地区の入口。幅 3〜4・同じ素材で、どこからでも背骨に2回の曲がりで戻れる。
- **輪**：背骨から出た道は行き止まりにせず、となりの地区を回って背骨に戻る（島を1周できる）。行き止まりは、眺め・目じるし・釣り場などのごほうびがある所だけ。
- **道の格**：背骨（幅3〜4）→ 地区の通り（幅2）→ 路地・小道（幅1）。格が下がるほど素材を地区のもの（郊外＝砂利、森＝土、日本＝飛び石、港＝石畳）へ寄せる。
- **道の固まりは作らない**：3×3 がまるごと道の所は「道」ではなく「空き地」。広場にするなら縁を囲んで名前をつける。
- **点検**：`island_check.py` の 4。飛行場からつながる道に、すべての目じるしとモジュールが1マス以内で触れていること（切れた道の島 0）。

## 2. 地区のならび：transect（なめらかな断面）

| 段 | 案2の地区 | 地面 | 建物の密度 | 木 |
|---|---|---|---|---|
| T6 都心 | ロンドン市内の中心（時計台・タワーブリッジ） | 舗装 9割以上 | 壁が連なる | 並木だけ |
| T5 町 | 市内のはし（テラスハウス・倉庫・港町） | 舗装 7割 | 家が並ぶ | 庭木 |
| T4 郊外の町 | 村・館・博物館 | 舗装 4割・庭 | 家が点々・塀と生け垣 | 庭木と果樹 |
| T3 田園 | 畑・牧草地・風車 | 生け垣で区切った畑 | 農家1つ | 生け垣の木 |
| T2 緑地帯 | 森・竹林のふち | 小道だけ | なし（小屋） | 林 |
| T1 自然・異界 | 森の奥・ハロウィン・日本の山 | 土・苔 | 1つの主役 | 深い林 |

- **となりの地区は1段ずつしか変えない**（T6 の隣に T2 を置かない）。2段以上ちがう所には、間の段の帯（4〜8マス）を入れる。
- **地区のさかいは地形のへりに乗せる**：崖・川・道・林の帯・塀。8×8 の区切りの線をそのまま使わない（点検 3：8割以上）。
- **さかいには門**：道がさかいをまたぐ所に、その地区の顔になる門（アーチ・鳥居・石の門柱・橋）を1つ。門の手前と奥で地面の素材を変える。
- **まぜる帯**：林の地区へ移るときは、木の密度を3段（まばら → 半分 → 林）で上げる。色（草の色・木の色）も帯の中で少しずつ変える。

## 3. 区画：どのモジュールも「囲まれた部屋」に入れる

- **北に背景**：建物の正面・壁・崖・林の尾根。あつ森のカメラは北を向くので、背景のない物は草の上に浮いて見える。
- **左右のうち少なくとも片側を囲む**：塀・生け垣・柵・となりの店。
- **南（手前）は開けて入口**：道が必ず1マス以上触れる。入口の前は物を置かない。
- **点検 2**：まわり1マスのうち4割以上が囲み（崖・木・水・物・道）で、道が触れていること。
- **何もない草地の上限**（点検 1、木・道・水・物から2マス以上はなれた草地の割合）：市内 10%・郊外 30%・森 15%・竹林 15%・日本 25%・ハロウィン 15%・港 25%。
  空けたいときは、縁を囲んだ芝生・牧草地・眺めの広場として**名前をつけて**空ける（ユーザーは名前のない空きを「空零零」と感じる）。
- **案内所の広場（地形 P）は何も置けない**：だから外側の1マスを道で囲み、街灯・並木・ベンチ・花壇で「わざと空けた広場」にする（第44回）。

## 4. 目じるし：大きいもの1つと、地区ごとに1つ

- **島の目じるし（global weenie）**：島の7割の場所から見える1つ。案2では時計台（ロンドン・2段目）。背骨はこれに向かってまっすぐ北へ。
- **地区の目じるし（local weenie）**：地区ごとに1つ、高い所か道の突き当たりに。館の塔・教会の尖塔・風車・社・お化け屋敷の塔・灯台。
- **小さな目じるし**：曲がり角ごとに1つ（電話ボックス・井戸・道しるべ・石灯籠）。
- **見せ方**：道の先に次の目じるしが見える（breadcrumb）。坂や階段を上がった所に眺め（vista）。主役の正面への道には背の高い物を置かない。
- **カメラは北向き**：背の高い物は北、低い物は南。南に背の高い物を置くと北の物が隠れる。

## 5. 密度とリズム

- 背骨を歩くと **にぎやか → ひと休み → にぎやか** がくり返す（通りの店 → 公園 → 市場 → 眺め）。同じ密度が続かない。
- 主役に細部の8割、脇役に1.5割、すき間に0.5割。全部を同じ細かさにしない。
- 1つの場面は3つの関係のある小物でできる（ベンチ＋新聞＋コーヒー）。ばらばらに30個より、意味のある3個。
- **ぼかしテスト**：鳥瞰図を強くぼかしても、背骨と地区の色の切れ目と目じるしが見えること。

## 6. 点検と作業の順番

```
python3 tools/island_check.py     # 1 何もない草地 2 浮いた物 3 さかいと地形 4 道のつながり
```

1. 点検の数を見る。悪い順に、**骨組み（4）→ さかい（3）→ 囲み（2）→ 草地（1）** の順で直す（家具から直さない）。
2. 道とさかいは `plan-design.json`（地形）と `designs/lon_paths.json`（道）で直し、`bash tools/build_all.sh` を通す。
3. 鳥瞰図で、ぼかしテスト・北向きの隠れ・目じるしの見え方を見る。
4. ユーザーの点数と言葉（「突兀」「空零零」「没利用好」）をこの skill の決まりに足す。
