# あつ森で作れるか（acnh-buildable）

> **基礎は `acnh-basics`（第48回）を先に読む**。この skill は第47回の「作れない物を描かない」決まり。第48回に直した所：木は「市松」ではなく、大きくした木を植えかえればくっつけてよい（崖・水・浜・建物・坂・橋のとなりは不可・190本まで）。壁かけとかさは外に置けない。入口の前は 3×2。崖の面には貼れないが、崖のすそにパネルを並べて壁に見せるのは作れる。

第46回の鳥瞰図は「完全脱离动森内部玩法 0分」だった。
摩天楼・崖に貼ったガラスのマイデザイン・ロンドン・アイ・DLR の高架・クレーン・数十軒の家（テラスハウス・コテージ・港の家並み）・館・教会・水車小屋を描いていたが、どれもゲームにない。
**絵がきれいでも、ゲームで作れない物は0点**。描く前に、この決まりで確かめる。

## 1. いちばん大事な決まり

- **建物はゲームの本物の建物だけ**：案内所（広場ごと動かせない）・飛行場（動かせない）・博物館 7×4・タヌキ商店 7×4・エイブル 5×4・キャンプ場 4×4・自宅 5×4・**住民の家 4×4 は10軒まで**。
  - 建物のまわり1マスは同じ段の平地（水・崖・砂浜・坂・橋にかからない）。建物どうしは1マスあける。入口の前1マスは物を置かない。
  - 住民の家の見た目は住民ごとに決まっている → 地区に合う外観の住民を選ぶ（designs/acnh_catalog.json の villagers に家の絵）。ハッピーホームパラダイスがあれば外観を変えられる。
  - 自宅の外観は案内所で選べる（屋根・壁・ドア・ポスト）。
- **家具は目録（designs/acnh_catalog.json）にある名前だけ**。大きさは目録どおり（1.5 や 0.5 は切り上げ）。英語のゲーム内の名前で書き、日本語名は目録の ja。
  - 「それらしい家具」を発明しない。似た物は目録で探す（例：ビッグ・ベン → ない、公園の時計 park clock。タワーブリッジ → レンガの橋 ＋ castle tower。ロンドン・アイ → plaza ferris wheel 3×2）。
- **マイデザインを貼れる所**：地面（道・地面の模様）と、模様を変えられる家具（simple panel など。PRO は かさ・うちわ・旗・顔出し看板）。**崖の面・水の面・建物の壁には貼れない**。
  - 「二階建ての店先」はシンプルなパネル（1×0.5・高さ約1.3マス）にレンガや窓のマイデザインを貼って並べる。パネルは積めない。
  - **崖のすそにパネルを並べると、崖がレンガの壁に見える**（作例 R-1233・X-0003・R-1217。第47回はこれを外して崖をむき出しにしたのはまちがい）。崖の上のふちには柵（レンガの柵など）。
- **地形**：崖は3段まで（4段目は登れない）。坂・橋は8本まで（ver 2.0 の建設ライセンスの追加で10本）、種類は8種類ずつ。橋の上・坂の上・案内所の広場には家具を置けない。崖は砂浜・岩にくっつけられない。
- **植物**：木は崖・水・浜・建物・坂・橋のとなりに植えられない。苗は8マス四方に木があると育たないが、大きくした木は植えかえてくっつけられる。木は190本くらいまで（第48回で直した）。ヤシは砂浜だけ。桜は4月はじめに広葉樹が咲くだけ（秋の島に桜は描かない）。花は8種類（バラ・チューリップ・パンジー・コスモス・ユリ・ヒヤシンス・アネモネ・キク）、作物は6種類（ver 2.0）。花と作物は草地だけ。動物（うさぎ・羊）は置けない。

## 2. 作り方の順番

1. 地区の考えを決めたら、まず**本物の建物を置ける平地**を探す（`designs/build_plan2.json` の buildings、`python3 tools/acnh_build.py`）。建物の土地がない地形はやめる（第47回：3段目の空の段・カナリー・ワーフの台座・キングス・クロスの高架をやめた）。
2. 道を建物の入口から引く（`plan2-design.json` の road）。
3. 家具のまとまり（groups）を、目録の名前で置く。柵・街灯・パネルは lines で列にする。花と作物は plants。果物の木は orchards。
4. `python3 tools/acnh_build.py` が NG 0、`python3 tools/island_check.py`（浮いた物・道のつながり）、`node tools/test_plan2.js` がすべて OK になるまで直す。
5. 鳥瞰図は、家具をゲームの絵（acnhcdn.com のアイコン）、住民の家をゲームの家の絵で描く（scratchpad の build47.py と acnh3d_tpl.html）。形を勝手に立てない。ゲームの絵はリポジトリに入れない。

## 3. 作れない物と、ゲームでの置きかえ（第47回の表）

| 描きたい物 | ゲームでは |
|---|---|
| 高層ビル・ガラスの壁 | ない。高台の住民の家・エイブルの並びで「町の壁」を作る |
| 時計台 | ない。park clock・plaza clock（1×1）|
| タワーブリッジ | brick bridge（橋の種類）＋ castle tower（2×2・ver 2.0）を両わきに |
| 観覧車・メリーゴーランド | plaza ferris wheel 3×2・plaza merry-go-round 3×3（どちらも ver 2.0 の小さな家具）|
| 汽車・バス・ポスト | ない（plaza train は子どもの乗り物）。バス停は retro transportation stop |
| 船 | yacht 3×2 だけ（陸か浜に置く）。いかりは anchor statue |
| 館・教会・社・お化け屋敷 | 建物にない。あずまや（azumaya gazebo）・ガゼボ・住民の家を見立てる |
| 水車 | ない。windmill（牧場の風車 2×2）|
| 墓石 | ない。stone tablet（せきひ）|
| うさぎ・羊 | ない。corral fence と hay bed の牧場 |

## 4. 出どころ

- データ：npm の animal-crossing@8.2.0（コミュニティの ACNH データ表）→ `tools/acnh_catalog_export.js` → `designs/acnh_catalog.json`
- 決まり：Nookipedia（Town・Incline・Bridge・Island_Designer・Plaza・Custom_design・Simple_panel・Fence・Tree・Villager_house・Flower）。URL は `designs/build_plan2.json` の rules.sources
- 建物の大きさは Reddit の測り方をまとめたページ（確かめきれていない。ゲームで確かめたら直す）
